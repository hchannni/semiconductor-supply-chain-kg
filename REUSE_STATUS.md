# Attribution and reuse

## License status

No dataset or example-code license has been specified in this repository. The presence of downloadable files does not itself state reuse permissions.

## Source attribution

`data/documents.jsonl` records Wikipedia page titles and URLs, SEC filing URLs, and available issuer, accession and publication metadata. These references identify the underlying sources. The graph is a derived research dataset; source attribution does not by itself establish redistribution rights. Source-specific terms and attribution requirements remain relevant to reuse.

## Distribution scope

The package includes graph records, document references, schema documentation, evaluation summaries and query examples. Article and filing bodies, quotation strings, benchmark tables and model-response caches are not included. The full extraction and graph-construction pipeline is not part of this repository.
